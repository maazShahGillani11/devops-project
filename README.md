# DevOps 3-Tier Application
BSE-8B Final Lab Project

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB

## Modules
- CI/CD: Jenkins
- Containerization: Docker
- Orchestration: Kubernetes
- IaC: Terraform
- Config Management: Ansible
- Monitoring: Prometheus + Grafana
- Security: Trivy + SonarQube
